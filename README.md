# Strongr

Personal Android workout tracker. Expo (React Native), TypeScript, local SQLite.

See [CLAUDE.md](CLAUDE.md) for the plan, architecture rules and decisions log.

## Run it on your phone

1. Install [Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent) on your Android phone.
2. `npm install`
3. `npm start`, then scan the QR code with Expo Go. Phone and computer must be on the same Wi-Fi (or use `npm start -- --tunnel`).

## Checks

`npm run check` runs the type checker, linter, format check and tests, the same as CI.
